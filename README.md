# メンズヘルス オンライン診療 モックサイト（デモ）

メンズヘルス（ED治療薬）オンライン診療サービスの **LP（ランディングページ）＋オンライン問診フロー** のフロントエンド完全モックです。投資家・社内デモ用に作成しています。

> **本サイトはデモ用モックです。実際の診療・販売・決済・データ保存は行いません。**
> 会社名・価格・サービス内容・リンク先はすべてデモ用のダミーです。

## 特徴

- すべてフロントエンド完結。バックエンド・API・DB・認証なし
- 問診の入力はメモリ上の state（`useReducer`）でのみ保持。**リロードで消えます**
- `localStorage` / `sessionStorage` は不使用
- 医療広告ガイドラインに配慮した穏当な表現（断定的・誇大表現を避ける）
- 既往歴で重い項目を選んだ場合、対面診療への誘導注意を表示する分岐ロジックを実装
- スマホ完全対応（モバイルファースト・レスポンシブ）

## 技術スタック

- Next.js 14（App Router）/ TypeScript
- Tailwind CSS
- lucide-react（アイコン）
- 状態管理は React の `useState` / `useReducer` のみ

## 起動手順

```bash
# 1. 依存をインストール
npm install

# 2. 開発サーバーを起動
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。
トップ `/` の CTA ボタンから `/consultation`（問診フロー）に進み、問診完了まで一通り操作できます。

本番ビルドの確認:

```bash
npm run build && npm start
```

## 問診フロー（`/consultation`）

ウィザード形式（進捗バー付き・前へ/次へ移動可・入力は state 保持）。

1. **はじめに** … 所要時間（約3分）と匿名・安心の案内
2. **基本情報** … 年齢（必須）、身長・体重（任意）
3. **生活習慣** … 喫煙・飲酒・運動（必須）
4. **既往歴・服薬** … 複数選択。高血圧・心疾患・硝酸薬など重い項目を選ぶと「対面診療をご案内する場合があります」と注意表示
5. **症状・希望** … 複数選択（必須）＋自由記述（任意1つ）
6. **確認** … 入力内容のサマリー
7. **完了** … 受付ダミーメッセージ → トップへ戻る

必須項目が未選択のときは「次へ」で進めず、エラーメッセージを表示します。

## コンプライアンス上の配慮

- 「治る」「必ず効く」「絶対」等の断定的・誇大な効能表現を不使用
- 性的・扇情的表現を避け、「健康・活力・自信」の文脈で穏当に記述
- 効能効果は「オンライン診療の提供」という事実の範囲にとどめる
- 価格・サービス内容を明朗に表示
- フッター等にデモである旨を明記
- 既往歴の重い項目選択時に対面診療への誘導を表示（医師法・オンライン診療指針への配慮を示すデモ）
